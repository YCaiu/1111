关于

本应用是开源项目 elanzuo/NeepWords 的移动端版本。原项目是一套本地考研英语词库工具集（词库检索 / 背诵表生成 / OCR 提取入库）， 运行方式是 macOS + Python 命令行；本应用把其中的词库检索、大纲归属判断与 A4 背诵表生成搬到了手机上，无需安装 Python，打开网页即可用，并可离线使用。

词库数据取自该项目仓库内置的只读示例数据库 words.sqlite3，为 2026 考研英语（一）考试大纲词汇，共 5624 词。软件代码遵循 MIT 许可； 词表数据的版权归考试大纲发布方所有，本应用仅供个人学习检索使用，请勿二次分发。
